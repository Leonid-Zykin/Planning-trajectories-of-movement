\chapter{ПЛАНИРОВАНИЕ ТРАЕКТОРИЙ ДВИЖЕНИЯ ДИНАМИЧЕСКИХ СИСТЕМ}

\section{Цель работы}

Исследование алгоритмов планирования траекторий движения динамических систем с использованием алгоритма A* и методов сглаживания траекторий.

\section{Задание}

\begin{enumerate}
\item Реализовать алгоритм A* для поиска пути на бинарной карте размером 10×10 с препятствиями. Найти путь от начальной точки до конечной точки с количеством поворотов не менее 3.

\item Сгенерировать траектории с разной степенью гладкости ($C^0$, C¹, C²) и B-сплайн сглаживание для найденного пути A*. Сравнить кривизны полученных траекторий.
\end{enumerate}

\section{Алгоритм A*}

\subsection{Математическая модель}

Алгоритм A* использует эвристическую функцию для поиска оптимального пути на графе. Для каждой ячейки вычисляется оценка:

$$f(n) = g(n) + h(n)$$

где:
\begin{itemize}
\item $g(n)$ --- стоимость пути от начальной точки до узла $n$
\item $h(n)$ --- эвристическая оценка стоимости от узла $n$ до цели
\end{itemize}

В данной работе используется манхэттенское расстояние как эвристическая функция:

$$h(n) = |x_n - x_{goal}| + |y_n - y_{goal}|$$

\subsection{Реализация алгоритма}

Алгоритм A* реализован с использованием приоритетной очереди (кучи) для эффективного выбора следующего узла для исследования. Используется 8-связность для движения по диагонали.

\section{Методы сглаживания траекторий}

\subsection{$C^0$-гладкая траектория (кусочно-линейная)}

$C^0$-гладкая траектория обеспечивает непрерывность функции без разрывов. Реализуется с помощью линейной интерполяции между точками пути A*:

$$f(t) = \text{interp1d}(t, \text{path\_points}, \text{kind='linear'})$$

\subsection{C¹-гладкая траектория (кубический сплайн)}

C¹-гладкая траектория обеспечивает непрерывность первой производной. Используется кубический сплайн с естественными граничными условиями:

$$f(t) = \text{CubicSpline}(t, \text{path\_points}, \text{bc\_type='natural'})$$

\subsection{C²-гладкая траектория (кубический сплайн)}

C²-гладкая траектория обеспечивает непрерывность второй производной. Используется кубический сплайн с закрепленными граничными условиями:

$$f(t) = \text{CubicSpline}(t, \text{path\_points}, \text{bc\_type='clamped'})$$

\subsection{B-сплайн сглаживание}

B-сплайн сглаживание использует базисные сплайны для создания гладкой траектории, которая не обязательно проходит через все точки пути A*:

$$f(t) = \text{UnivariateSpline}(t, \text{path\_points}, \text{s=smoothing\_factor}, \text{k=3})$$

\subsection{Статистика кривизн}

Результаты моделирования показали следующие характеристики кривизн:

\begin{itemize}
\item \textbf{$C^0$-гладкая (линейная):} средняя = 0.7598, максимальная = 111.0000
\item \textbf{C¹-гладкая (кубический сплайн):} средняя = 0.9710, максимальная = 4.6861
\item \textbf{C²-гладкая (кубический сплайн):} средняя = 1.0420, максимальная = 25.6972
\item \textbf{B-сплайн сглаживание:} средняя = 0.1189, максимальная = 0.1800
\end{itemize}

\subsection{Сравнение методов}

\textbf{$C^0$-гладкая траектория:}
\begin{itemize}
\item Обеспечивает минимальную длину пути
\item Имеет острые углы в точках поворота
\item Высокая максимальная кривизна в углах
\end{itemize}

\textbf{C¹ и C²-гладкие траектории:}
\begin{itemize}
\item Обеспечивают плавные переходы между сегментами
\item Умеренная кривизна по всей траектории
\item Хорошо подходят для робототехнических применений
\end{itemize}

\textbf{B-сплайн сглаживание:}
\begin{itemize}
\item Обеспечивает наименьшую среднюю и максимальную кривизну
\item Создает наиболее плавную траекторию
\item Может отклоняться от исходных точек пути A*
\end{itemize}

\section{Выводы}

В ходе выполнения лабораторной работы были реализованы и исследованы различные методы планирования и сглаживания траекторий:

1. \textbf{Алгоритм A*} успешно находит оптимальный путь на бинарной карте с препятствиями, обеспечивая минимальное количество шагов при обходе препятствий.

2. \textbf{Методы сглаживания} позволяют создавать траектории с различной степенью гладкости, что важно для практических применений в робототехнике.

3. \textbf{B-сплайн сглаживание} обеспечивает наилучшие характеристики по кривизне, но требует дополнительной проверки на коллизии с препятствиями.

4. \textbf{Выбор метода сглаживания} зависит от требований конкретного применения: для минимизации длины пути используется $C^0$-гладкая траектория, для плавности движения --- C¹/C²-гладкие траектории, для максимальной гладкости --- B-сплайн.

5. \textbf{Практическая значимость} работы заключается в возможности применения разработанных алгоритмов для планирования траекторий мобильных роботов, беспилотных летательных аппаратов и других динамических систем.
